# Datos de Gasolineras Cerca

Servicios de todas las gasolineras de España (aseos, cafetería, tienda, lavado, cargadores eléctricos…) para la app **Gasolineras Cerca**.

- Se generan **solos el día 1 de cada mes** a partir de OpenStreetMap (descarga de Geofabrik).
- Para generarlos a mano: pestaña **Actions** → **Servicios de gasolineras** → **Run workflow**.
- Se publican en GitHub Pages: `https://<usuario>.github.io/gasolineras-datos/`
